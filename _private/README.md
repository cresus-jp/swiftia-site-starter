# \_private/ — 公開されない作業用ディレクトリ

**このディレクトリの中身は公開サイトに配信されません。** リポジトリにはコミットされるので、
案件の関係者全員が clone で受け取れます。

## ここに置くもの

- 仕様書（Excel / PDF）
- 顧客支給の原稿・素材（ロゴの元データ、写真の原本など）
- 案件メモ、打ち合わせ議事録

## ここに置いてはいけないもの

- **パスワード・APIキー・アクセストークン**。リポジトリの閲覧権限を持つ全員が読めます。
  配信されないことと秘密が守られることは別問題です
- **巨大なバイナリ**（動画、数百MBのPSD/AI）。Git リポジトリが肥大化して clone が重くなります。
  仕様書の Excel / PDF 程度なら問題ありません

## なぜ配信されないのか

`.github/workflows/deploy.yml` が、配信物をステージングディレクトリへコピーする際に
このディレクトリを除外しています（`--exclude '_private'`）。

**逆に言うと、除外リストに無いファイルはすべて公開されます。**
リポジトリ直下に置いたファイルは `https://サイトのドメイン/ファイル名` でダウンロードできる状態になるため、
公開したくないファイルは必ずこのディレクトリに入れてください。
