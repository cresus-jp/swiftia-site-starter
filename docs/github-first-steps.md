# GitHub はじめてガイド（アカウント作成〜最初のクローン）

**対象**: これから案件に参加する、GitHub を使ったことがないデザイナーさん
**ゴール**: GitHub のアカウントを作り、案件の「リポジトリ」（ファイル置き場）を自分のパソコンにコピーして、中のドキュメントを読める状態になること

このガイドは、案件リポジトリを受け取る**前**の準備だけをまとめた 1 枚ものです。ここまで終われば、この先の手順書（Git かんたんマニュアル・コーディングガイドライン）は**リポジトリの中に入っています**。

**全体の流れ**（所要 30 分〜1 時間。ほとんどはインストールの待ち時間です）:

```
① GitHub アカウントを作る（10分）
② ユーザー名を担当者に伝えて、招待を受ける（5分）
③ パソコンに Git を入れる（10〜30分）
④ 案件リポジトリをクローンする（5分）→ 完了！
```

---

## ① GitHub アカウントを作る

GitHub（ギットハブ）は、案件のファイル置き場（リポジトリ）をインターネット上で保管・共有するサービスです。無料で使えます。

1. ブラウザで [github.com/signup](https://github.com/signup) を開く
2. 次の 3 つを入力して進みます
   - **メールアドレス**: 仕事用のものを推奨
   - **パスワード**: 15 文字以上、または「8 文字以上＋数字と小文字を含む」
   - **ユーザー名**: 半角英数字とハイフンのみ。仕事で使うので**本名ベースが無難**です（例: `hanako-yamada`）。あとから変えると混乱のもとになるので、最初にちゃんと決めましょう
3. 入力したメールアドレスに届く**確認コード**を入力すれば、アカウント完成です
4. **2 段階認証（2FA）の設定を求められたら**: 「Authenticator app」を選び、スマホに認証アプリ（Google Authenticator など）を入れて画面の QR コードを読み取るのが標準的です。SMS（電話番号）でも構いません。最後に表示される**リカバリーコードは必ずスクリーンショット等で保存**してください（スマホをなくしたときの命綱です）

---

## ② ユーザー名を担当者に伝えて、招待を受ける

案件のリポジトリは非公開なので、招待された人しか見られません。

1. ①で作った**ユーザー名**を、担当者（コーディネーター／エンジニア）に連絡してください
2. 担当者が招待すると、登録したメール宛に「**invited you to collaborate**」というメールが届きます
3. メール内の **View invitation** → **Accept invitation** をクリック
4. ブラウザで案件リポジトリのページが表示されるようになれば OK です

> この時点で、リポジトリの `docs/` フォルダにある各種マニュアルをブラウザで読めるようになります（ファイル名をクリックすると内容が表示されます）。

## ③ パソコンに Git を入れる

Git（ギット）は、ファイルの変更履歴を記録しながらリポジトリとやりとりするための道具です。お使いのパソコンに合わせてどちらかを行ってください。

### Mac の場合

1. **ターミナルを開く**: キーボードで **⌘（コマンド）+ スペース** → 「**ターミナル**」と入力して **Enter**。白い（または黒い）画面が開きます。ここにコマンドを貼り付けて Enter で実行します
2. 次の 1 行を貼り付けて Enter:
   ```
   git --version
   ```
   - `git version 2.39.0` のような表示が出たら → もう入っています。手順 3 へ
   - 「コマンドライン・デベロッパツールをインストールしますか？」と出たら → 「**インストール**」をクリックして待ちます（10〜30 分かかることがあります）。終わったらもう一度 `git --version` で確認
3. **Git Credential Manager を入れる**（GitHub への本人確認をブラウザのログインだけで済ませてくれる道具です）
   - ブラウザで [git-credential-manager の Releases ページ](https://github.com/git-ecosystem/git-credential-manager/releases/latest) を開く
   - `gcm-macos-...pkg` をダウンロード。**arm64** と **x64** の 2 種類があるので、アップルメニュー →「このMacについて」で「チップ」に **Apple** とあれば arm64、**Intel** とあれば x64 を選びます
   - ダウンロードした `.pkg` をダブルクリックしてインストール（「開発元を確認できない」と出たら、ファイルを右クリック → 開く）

### Windows の場合

1. ブラウザで [gitforwindows.org](https://gitforwindows.org/) を開き、「**Download**」をクリック
2. ダウンロードしたファイルをダブルクリックして実行。選択肢がたくさん出ますが、**すべてそのまま「Next」で OK** → 最後に「Install」→「Finish」
3. スタートメニューで「**Git Bash**」と入力して起動してみてください。黒い画面が開けば成功です。ここにコマンドを貼り付けて Enter で実行します（**貼り付けは画面の上で右クリック → Paste** です。Ctrl+V が効かないことがあります）

> GitHub への本人確認の道具（Git Credential Manager）は、Git for Windows に最初から入っています。

## ④ 案件リポジトリをクローンする

クローン（clone）＝ GitHub 上のリポジトリを自分のパソコンにまるごとコピーすることです。案件ごとに最初の 1 回だけ行います。

1. 担当者から案件リポジトリの **URL** をもらいます（例: `https://github.com/cresus-jp/○○○-site`）
   - 自分で調べる場合: ブラウザでリポジトリのページを開き、緑色の「**<> Code**」ボタン → **HTTPS** タブの URL をコピー
2. ターミナル（Windows は Git Bash）で、置き場所（ここではデスクトップ）に移動します:
   ```
   cd ~/Desktop
   ```
   > Windows で `No such file or directory` と出た場合は、デスクトップが OneDrive 管理になっています。`cd ~/OneDrive/Desktop` を実行してください。
3. クローンします（URL は自分の案件のものに書き換えてください）:
   ```
   git clone https://github.com/cresus-jp/○○○-site.git
   ```
4. **初回はブラウザ（またはログインウインドウ）が自動で開きます**。GitHub にログインして「Authorize」を押してください。次回からは聞かれません
5. デスクトップに案件名のフォルダができていれば**完了です！**

## こまったとき

**Q. 招待メールが見当たらない**
A. ブラウザで GitHub にログインして [github.com/notifications](https://github.com/notifications) を確認してください。それでも無ければ、担当者にユーザー名が正しく伝わっているか確認を。

**Q. クローンで `Repository not found` と言われた**
A. 招待をまだ承諾していない可能性が高いです（手順②）。または URL の打ち間違いです。

**Q.（Mac）ブラウザが開かず、ターミナルで Username を聞かれた**
A. Git Credential Manager が入っていません。手順③-3 を行ってから、もう一度クローンしてください。
